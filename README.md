## Editing the website

- `index.html` is the short GitHub Pages/Jekyll entry point. Pages builds it into a complete HTML page; opening this source file by itself locally will not render the includes.
- `_includes/site-original.html` preserves the complete working website and its eight embedded photos, unchanged from the restored version. Do not replace this large file with a blank browser-editor buffer.
- `_includes/faq.html` contains the expandable frequently asked questions.
- `_includes/site-enhancements.css` contains the new sections' styling.
- `_includes/quick-contact.html`, when present, contains the mobile Call / Text / Get a Quote bar.

Pages remains configured to publish from `main` and `/ (root)`. No additional accounts, build settings, or packages are required for the GitHub Pages build.

Keep contact details and pricing consistent with `SITE` in the original website. These additions do not change how reviews or quote requests are sent: the forms prepare emails that visitors must send themselves. Fictional review examples in the original preview remain labeled; replace or remove those examples before a commercial launch.
